💜 Neon Music Downloader Pro (PySide6)

Современный, легкий и полностью автономный десктопный загрузчик аудио с YouTube, написанный на **Python** с использованием Enterprise-фреймворка **PySide6 (Qt6)** и движка **yt-dlp**.

## 🚀 Особенности (Features)
- 🛸 **Cyberpunk UI:** Стильный кастомный интерфейс в темных и неоново-фиолетовых тонах, сверстанный через QSS-стили.
- ⚡ **Async Architecture:** Загрузка полностью вынесена в изолированный асинхронный поток `QThread`. Интерфейс приложения никогда не фризится и не лагает.
- 📊 **Real-time Progress:** Динамический фиолетовый ProgressBar, отображающий точный процент скачивания трека.
- 🎶 **Playlist Support:** Утилита умеет парсить и последовательно скачивать целые музыкальные плейлисты.
- 🛑 **Smart Cancel:** Возможность в один клик мгновенно и безопасно остановить скачивание огромного плейлиста кнопкой «Стоп».
- 📁 **Path Selection:** Удобный выбор любой папки или диска (включая флешки) для сохранения музыки.
- 🎧 **Quick Play:** Воспроизведение скачанного MP3-файла в системном плеере по двойному клику на трек прямо из списка.

## 🛠️ Технический стек (Stack)
- Python 3
- PySide6 (Qt6)
- yt-dlp
- FFmpeg (для конвертации в чистый MP3 192k
